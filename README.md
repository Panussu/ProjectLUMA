# ProjectLUMA QA

สาขานี้ดูแลชุดทดสอบ Python, GitHub Actions และแผนตรวจระบบก่อนสาธิต คอมเมนต์ภาษาไทยระบุวัตถุประสงค์ของแต่ละกรณีทดสอบและข้อมูลจำลอง

## ขอบเขตการทดสอบ

ชุดทดสอบตรวจการสมัครสมาชิก JWT สิทธิ์เจ้าของงาน การอัปโหลด การสร้างและแก้ไขภาพ รวมถึงการแปลงคำขอ Forge โดยใช้คำตอบจำลอง จึงไม่ต้องใช้ GPU ในการทดสอบอัตโนมัติ

## วิธีตรวจระบบรวม

สาขา QA ไม่มีโค้ดบริการครบชุด ให้รวมการแก้ไขชุดทดสอบเข้ากับ `main` แล้วรันจากสาขารวม

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest
node --check frontend/assets/app.js
docker compose config --quiet
```

การตรวจอัตโนมัติไม่ยืนยันการสร้างภาพด้วยโมเดลจริงหรือเครือข่าย 3 เครื่อง ต้องทำตาม [แผนทดสอบ](docs/TEST_PLAN.md) ด้วย IP และโมเดลที่ใช้สาธิต พร้อมเก็บผลการสร้าง แก้ไข ดาวน์โหลด และแยกสิทธิ์บัญชี
