# ProjectLUMA Routing

สาขานี้ดูแล Nginx บน PC 2 เส้นทางเครือข่าย สคริปต์เริ่มบริการ และไฟล์ Docker สำหรับการสาธิต 3 เครื่องใน VLAN เดียวกัน คอมเมนต์ภาษาไทยอธิบายแต่ละบล็อกของค่ากำหนด

## เส้นทางคำขอ

- `/` และไฟล์หน้าเว็บให้บริการจาก PC 2
- `/api/` ส่งไป Flask บน PC 3 พอร์ต 5000
- `/media/` ส่งไป Flask เพื่อตรวจสิทธิ์และอ่านภาพ
- `/health` ส่งไป `/api/v1/health` ของ Flask

Flask ติดต่อ FastAPI บน PC 1 พอร์ต 8000 และ FastAPI เรียก Forge บน localhost พอร์ต 7860

## ติดตั้งและตรวจค่า

เปลี่ยน IP ตัวอย่างใน `nginx/luma.conf` ให้ตรงกับผล `ipconfig` และตั้ง root ไปยังโฟลเดอร์ Frontend จริง วาง `nginx.conf` กับ `luma.conf` ในโฟลเดอร์กำหนดค่าเดียวกัน ตรวจด้วย `nginx.exe -t` ก่อนเริ่มหรือโหลดค่าใหม่

อ่าน [คู่มือ 3 เครื่อง](PROJECTLUMA_3PC_TEST_GUIDE.md), [การติดตั้ง](docs/DEPLOYMENT.md) และ [สถาปัตยกรรม](docs/ARCHITECTURE.md)

สาขานี้เก็บไฟล์การติดตั้งแต่ไม่มีโค้ดแอปครบทุกบริการ จึงต้องใช้สาขา `main` เพื่อรันสคริปต์บริการหรือสร้างชุด Docker ครบระบบ
