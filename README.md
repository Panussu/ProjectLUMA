# ProjectLUMA AI Engine

สาขานี้เป็นงาน PC 1 ที่รัน FastAPI และ WebUI Forge ผ่าน Stability Matrix รับงานจาก Flask บน PC 3 แล้วส่งภาพ PNG กลับ คอมเมนต์ภาษาไทยอธิบายการตรวจข้อมูล การแปลงคำขอ และ provider ทดสอบ

อ่าน [คู่มือ AI Engine](ai-engine/README.md) สำหรับการติดตั้ง ตั้งค่าโทเคนร่วม และเปิดบริการภายใน VLAN เดียวกัน

สาขานี้มีเฉพาะบริการ AI ให้ใช้ `main` เมื่อต้องการ Frontend, Backend, Nginx และชุดทดสอบครบระบบ
