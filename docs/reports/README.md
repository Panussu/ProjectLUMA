# รายงานประกอบการตรวจเว็บภายนอก

[ดาวน์โหลดรายงาน Word ภาษาไทย](LUMA_Visible_Bug_Report_TH.docx)

เอกสารนี้ตรวจเว็บ `boss2912/luma-webapp-g04` ผ่านเบราว์เซอร์เมื่อวันที่ 14 ตุลาคม 2026 โดยทดสอบก่อนและหลังเข้าสู่ระบบด้วยบัญชีทดสอบที่ได้รับอนุญาต รายงาน 23 หน้ามีภาพหลักฐาน 12 ภาพ พร้อมขั้นตอนที่ทำให้เกิดปัญหา ผลที่พบ ผลที่ควรเป็น ผลกระทบ และแนวทางแก้ไข

รวมประเด็นที่ยืนยันจากหน้าจอ 7 รายการ และข้อเสนอแนะด้านการใช้งาน 1 รายการ ประเด็นก่อนเข้าสู่ระบบบางรายการมีอาการเกี่ยวข้องกัน และเหตุการณ์ 502 พบหนึ่งครั้งก่อนกลับมาใช้งานได้หลังรีเฟรช ข้อเสนอแนะเรื่องคำแนะนำรหัสผ่านแยกจากบั๊กการทำงาน

ข้อผิดพลาดที่พบเพิ่มเติมหลังเข้าสู่ระบบ ได้แก่ ข้อมูลกรอบเบลอไม่ตรงกับกรอบที่ส่งหลังลากออกนอกภาพ และการนำค่า `1e1` กับ `1e3` ใน Steps และ Seed ไปใช้เป็น `1` แทน `10` และ `1000`

เอกสารนี้เก็บเป็นหลักฐานการตรวจเว็บภายนอก ไม่ใช่รายงานว่าข้อผิดพลาดดังกล่าวเกิดใน `Panussu/ProjectLUMA` ผลตรวจของโปรเจกต์นี้อยู่ใน [WEBAPP_AUDIT_2026-10-14.md](../WEBAPP_AUDIT_2026-10-14.md)
